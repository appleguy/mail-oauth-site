Personal Mail Tools

This is a private, owner-operated deployment of email management tools, including the open-source Inbox Zero interface and a local Google Workspace CLI (gog).

Its purpose is to search and review Gmail messages and conversations, summarize mailbox activity, and optionally help organize email with the account owner's permission. There is no public signup or hosted email service here.

For initial setup, the local Gmail CLI requests read-only access. Optional inbox-organization features may request broader permissions when explicitly configured.

This site is informational only. It does not host the Gmail application or collect Google account credentials, email, or mailbox data.

Independent personal deployment; not affiliated with Google or the upstream Inbox Zero team.
